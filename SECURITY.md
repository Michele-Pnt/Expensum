# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull
requests. Use GitHub's private vulnerability reporting for this repository,
or contact a maintainer privately through GitHub if that feature is unavailable.

Include the affected component, steps to reproduce, and potential impact. Do
not include real user data, access tokens, or other secrets in a report.

The maintainers will acknowledge reports as soon as practical, investigate
them, and coordinate any fix and disclosure with the reporter. There is no
guaranteed response or remediation timeline at this time.

## Supported versions

Only the latest version on the default branch is currently supported. No
security support period is offered for older releases.
